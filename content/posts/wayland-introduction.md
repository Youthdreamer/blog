X11 诞生于 1987 年，比很多人年纪都大。它带着太多历史包袱：复杂、权限模型松散、屏幕撕裂、混合器的补丁越堆越多。

Wayland 是它的继任者，一个从零设计的显示协议。

## Wayland 到底改变了什么

X11 里，客户端和显示服务器之间是一大堆协议和扩展。Wayland 把这些简化成"客户端直接把内容画进缓冲区，合成器把它们拼到屏幕上"。

- 没有屏幕撕裂
- 每个窗口天然隔离（更安全）
- 更少的转发、更少的延迟

## 代价

代价是：**旧工具不兼容**。截图、录屏、输入法、远程桌面……这些曾经依赖 X11 的东西，都要用 Wayland 的新方式重做。

```bash
# Wayland 下看当前会话类型
echo $XDG_SESSION_TYPE
# wayland
```

## 现状

2025 年的今天，GNOME 和 KDE 都默认 Wayland，主流应用基本跟上了。对大多数人来说，迁移是顺滑的。

> X11 不会消失，但它已经是"过去"了。
