凌晨一点十七分。屏幕的光把房间切成两半：亮的一半是代码，暗的一半是生活。

最后一个 bug 刚刚被消灭。它藏在一个 `off-by-one` 的错误里——数组的边界，`i < length` 还是 `i <= length`，差一个字符，差一个小时。

## 深夜的三种声音

深夜写代码的人，耳朵里通常有三种声音：

1. **风扇声** —— 机器的呼吸，比人均匀
2. **键盘声** —— 唯一允许的噪音
3. **沉默** —— 自己心里那个"再试一次"的声音

凌晨的代码有一种奇特的质地：白天写代码像是在人群里说话，要照顾语法、风格、别人的眼光；深夜写代码，是在跟自己商量，_这段逻辑，到底该怎么走_。

## 凉透的茶

茶杯已经凉透了。据说茶凉了以后，苦味会变淡，回甘会变明显——不知是真是假，但深夜的茶似乎确实更好喝一点。也许不是茶变了，是**尝茶的人变了**。

> 深夜写的不是代码，是白天来不及说的话。

## 跑通的那一刻

程序跑通的那一刻，世界忽然安静下来。不是因为声音消失了，而是因为**心里的噪音停了**。

屏幕上滚过绿色的输出，像一封远方寄来的回信：

```bash
$ node build.js
✓ 4 posts built
✓ styles copied
done in 0.38s
```

0.38 秒。而为了这 0.38 秒，我坐了四个小时。很划算，不是吗？

## 天亮之前

明天太阳照常升起，代码照常要改。但今晚的这一个瞬间，是完完全全属于我的：

> 一台电脑，一盏灯，一个跑通的程序，和一个满意的我。

晚安，深夜写代码的人。茶已经凉了，但你心里是暖的。
