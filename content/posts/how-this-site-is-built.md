很多人问我（其实没有人问我），这间屋子是怎么盖起来的。答案可能会让你意外：**没有用任何框架**。

不是框架不好，而是我想要的，是一种"每一条线都是我画的"的感觉。博客的排版、配色、动效，应该像一个人的笔迹一样独一无二。所以这间屋子的全部家当，只有四样东西：

1. 一个 `build.js` —— 零依赖的构建脚本
2. 一张 `style.css` —— 手写的全部样式
3. 一个 `main.js` —— 一点入场动画和小彩蛋
4. 一堆 `.md` 文件 —— 文章本身

## 构建脚本：两百行，够用

文章用 Markdown 写，构建时解析成 HTML。核心逻辑其实很短：

```js
// build.js 的一小部分
function mdToHtml(src) {
  const lines = src.split('\n');
  let html = '';
  for (const line of lines) {
    if (line.startsWith('## ')) html += `<h2>${inline(line.slice(3))}</h2>\n`;
    else if (line.startsWith('- ')) html += `<li>${inline(line.slice(2))}</li>\n`;
    else html += `<p>${inline(line)}</p>\n`;
  }
  return html;
}
```

当然真实版本处理了标题、引用、代码块、列表、粗体斜体……但精神是一样的：**只解决自己遇到的问题**。两百行，每一个字符我都认识。

## 配色：香槟金要用得克制

深色的底，配一点香槟金。金色是危险的颜色——用得多了就俗，用对了才高级。我的原则是：

- 金色只出现在**需要被看见**的地方：链接、标记、印章
- 正文永远用纸白色，让阅读保持安静
- 分隔线都是发丝一样细的 `1px`

```css
:root {
  --bg:      #12100e;   /* 墨色底 */
  --ink:     #e8e2d6;   /* 纸白字 */
  --accent:  #b9a37c;   /* 香槟金 */
}
```

## 字体：三套各司其职

- **Cormorant Garamond** —— 拉丁大标题，斜体的时候最好看
- **思源宋体** —— 中文正文，横竖撇捺都从容
- **JetBrains Mono** —— 小字号的元信息，如日期、标签、页码

宋体负责"读"，衬线负责"看"，等宽字体负责"记"——三种节奏，互不打扰。

## 一些没用但有趣的部分

这间屋子还有两个彩蛋：在键盘上敲出 `youth`，或者连点三次页脚的印章，会有一句暗号浮上来。为什么要有彩蛋？因为——

> 一间完全理性的屋子，住起来会很孤独。

设计里留一点"无用之物"，人才会觉得这里**有人住过**。

## 最后

盖屋子的过程本身，就是这间屋子最好的文章。工具不在多，在于顺手；设计不在繁，在于真诚。愿你也有一间属于自己的小屋。
