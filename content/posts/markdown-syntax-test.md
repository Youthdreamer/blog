## 粗体与斜体

**粗体**、*斜体*、***粗斜体*** 混排：**粗体**和*斜体*可以紧挨着写，也可以**粗体 *斜体* 互相嵌套**。含星号的内容也能加粗：**a*b**。

英文单词中间的单星号不应误渲染：a*b*、foo*bar*baz。

删除线也可以包粗体：~~**粗体删除线**~~，反过来 **~~删除线粗体~~** 也可以。

## 代码块

围栏代码块（带语言标注）：

```js
function greet(name) {
  // 注释里的 <b>不会被解析</b>
  return `hello, ${name}!`;
}
```

无语言标注的代码块，内容中的 `<script>`、`&` 等应被转义：

```
<b>&</b>  <script>alert(1)</script>
```

## 嵌套组合

各种行内语法互相嵌套：

- **粗体套斜体**：`**粗*斜*粗**` 渲染为 **粗*斜*粗**
- **斜体套粗体**：`*斜**粗**斜*` 渲染为 *斜**粗**斜*
- **粗体套代码**：`**a \`b\` c**` 渲染为 **a `b` c**
- **粗体套链接**：`**看[链接](https://example.com)**` 渲染为 **看[链接](https://example.com)**
