tmux 是我工具箱里最"无感"却又最离不开的工具。

它把终端分成**会话、窗口、窗格**三层结构，让你在一个终端里同时开很多"工作区"。

## 三个核心概念

- **会话（session）** —— 一个完整的工作环境，可以断开后重连
- **窗口（window）** —— 会话里的标签页
- **窗格（pane）** —— 一个窗口内的分屏

```bash
tmux new -s work       # 新建会话
tmux attach -t work    # 重连会话
Ctrl-b %               # 垂直分屏
Ctrl-b "               # 水平分屏
```

## 常用快捷键

| 快捷键 | 作用 | 层级 |
| :--- | :---: | ---: |
| `Ctrl-b %` | 垂直分屏 | 窗格 |
| `Ctrl-b "` | 水平分屏 | 窗格 |
| `Ctrl-b c` | 新建窗口 | 窗口 |
| `Ctrl-b d` | 脱离会话 | 会话 |
| `Ctrl-b [` | 进入复制模式 | 窗口 |

## 为什么离不开

最大的理由是：**SSH 断了，你的工作还在**。连回服务器，`tmux attach`，一切原样。

> 终端里的东西，不该因为一次断网就烟消云散。

## 一点配置

配合一个好用的前缀键和状态栏，tmux 会从"能用"变成"好用"。我的前缀键从默认的 `Ctrl-b` 改成了 `Ctrl-a`，顺手很多。
