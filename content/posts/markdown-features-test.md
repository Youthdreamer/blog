这是一篇功能测试文档，覆盖当前博客 Markdown 解析器支持的全部语法。页面顶部应出现目录（本文有 15 个小节）。文章首段的首字应显示"下沉 + 金色"效果（仅首段）。

## 标题与段落

`#` 到 `######` 都支持，其中 `##` 和 `###` 会生成锚点并计入目录，其余层级仅渲染。段落支持多行合并、两端对齐。

普通段落文字。段落内可以**混排**各种行内语法：**粗体**、*斜体*、`代码`、[链接](https://example.com)、~~删除线~~。

## 粗体与斜体

- **粗体** `**粗体**`
- *斜体* `*斜体*`
- ***粗斜体*** `***粗斜体***`
- 嵌套：**粗体 *斜体* 互相嵌套**、*斜体**粗体**斜体*
- 粗体内容含星号：**a*b**（字面星号保留）
- 粗体套代码：**看 `code` 加粗**；粗体套链接：**看[链接](https://example.com)**
- 英文单词中间的单星号不误渲染：a*b*、foo*bar*baz

## 代码块

围栏代码块（` ``` ` 三个反引号，可带语言标注）：

```js
function greet(name) {
  // 注释里的 <b>不会被解析</b>
  return `hello, ${name}!`;
}
```

无语言标注的代码块，内容中的 `<script>`、`&` 等应被转义显示：

```
<b>&</b>  <script>alert(1)</script>
```

行号表标行：围栏信息里写 `{2,4-5}`，第 2 行与第 4–5 行应落一条淡金色带（左缘一条 2px 金条，长行横向滚动时带跟着字走）：

```lua {2,4-5}
local lazypath = vim.fn.stdpath("data") .. "/lazy/lazy.nvim"
vim.opt.rtp:prepend(lazypath)
local lazy = require("lazy")
lazy.setup("plugins", {
  spec = { { "folke/tokyonight.nvim", lazy = false, priority = 1000, opts = {} } },
})
```

行号规矩：`N` 单行、`N-M` 区间，逗号分隔；排序后相连的也合并，倒着写按正序算，单行超出实际行数整条丢弃（写错了构建日志会提醒一句）。

## 键帽

Neovim 教程通篇快捷键，行内代码和按键混在一起不够醒目——把按键写成 `[[Ctrl+w]]`，渲染成一枚键帽：

按 [[Ctrl+w]] 切窗口，按 [[q]] 退出，[[<C-w>]] 也算字面（尖括号转义）。

整串就是一个键帽（字面就是键帽上印的字样），不拆 `+`；想写字面的 `[[x]]`，用行内代码包住即可：`[[x]]`。

## 剧透遮罩

一句话的剧透用 `||…||` 盖住：默认模糊着，点一下（或键盘回车 / Tab 聚焦）显形，揭开就不再合上。

结局其实是 ||他一直在等你||。内容照常走行内语法：||**加粗的剧透** 和 `代码`|| 都能写。

（遮的是屏幕上的余光：复制拿到的仍是原文、读屏照读、打印直接显形。）

空遮罩 `||||`、没闭合的 `||` 都原样输出；正文里裸写两个不相干的 `||` 会被配成遮罩——不想被配就用行内代码包住（这段话里出现的都包住了）。表格单元格里写不了（`|` 是列分隔符）。

## 折叠块

`fold` 围栏生成一个默认合着的折叠块：第一行是露在外面的提示语，其余是折起来的正文。合着时应有金边、极淡斜纹封条与 ◆ 菱形，右侧标「点开揭晓」；点开后封条褪去、分隔线浮出，◆ 转 ◇、字样换成「收起」，高度平滑展开。

```fold
剧透警告：下面要讲结局了
结局其实是……（把想藏的话写在这里，**行内语法**照常解析）
```

正文里要放代码块，用**四个反引号**开栅（三反引号留给里面的代码）：

````fold
展开核对答案
```js
const answer = 42;
```
````

折叠正文里的标题不进目录、评分卡不挂列表徽标（合着的内容不在外面留痕）。正文一行都没有（或只有提示语）时整块跳过，构建日志里提醒一句。

## 提示框

`note` 围栏生成一张旁批便笺：整段都是正文，照常写 markdown，渲染成淡金晕底、发丝描边的小盒，左缘一枚 ◆ 对着第一行（旁批记号）。

```note
改配置前先**备份**。这个小盒就是 `note` 围栏渲染出来的效果——正文是纸白正体（不斜体，斜体是引用块的腔调）。
```

正文里要放代码块（或嵌别的围栏），同样用**四个反引号**开栅：

````note
先备份再动手：

```bash
cp hyprland.conf hyprland.conf.bak
```
````

便笺里的标题不进目录、评分卡不挂列表徽标（与折叠块同一规矩）。一行内容都没有时整块跳过，构建日志里提醒一句。若正文里直接写三反引号的 ` ```score `、` ```note ` 之类，会把外层的块提前关掉——构建日志会提醒你改用更长的围栏开栅。

## 脚注

正文写 `[^1]`，文末写 `[^1]: 内容`，构建时自动汇总成「脚注」区[^auto]——本文的几条定义就统一放在了全文最末，构建时自动归位。号码按**首次引用顺序**发，与定义摆放次序无关；同一标签第一处带回跳锚点，点号码跳进区里、点区尾的 ↩ 跳回原处。

引用写在**粗体里[^bold]**、||遮罩里[^hide]||都照常认：

```fold
点开看看
折叠块的正文里写引用[^folded]，也能汇总到文末。
```

定义正文照常走行内语法，站内 `./xxx.md` 链接白捡改写[^link]。重复定义只认第一个、没定义的引用原样保留、没人引用的定义丢掉——都只在构建日志提醒，不挡构建。

> 引用块里也行[^quoted]——引用、列表、折叠块、提示框里的引用与定义都会汇总到文末的「脚注」区。

## 分隔线与嵌套组合

分隔线 `---` 或 `***`：

---

各种行内语法互相嵌套：

- **粗体套斜体**：`**粗*斜*粗**` 渲染为 **粗*斜*粗**
- **斜体套粗体**：`*斜**粗**斜*` 渲染为 *斜**粗**斜*
- **粗体套代码**：```**a `b` c**``` 渲染为 **a `b` c**
- **删除线互套**：~~**粗体删除线**~~ 与 **~~删除线粗体~~**

## 转义与容错

特殊字符应转义：`<b>标签</b>`、`1 < 2 > 0`、`A & B`。

未闭合的标记原样输出：**没闭合、~~没闭合、[没闭合。

4 空格缩进的行不会被当作列表（缩进限制）：`    1. 这不是列表`。

## 总结

以上验证了：标题（含锚点与目录）、段落、粗体/斜体/粗斜体及嵌套、删除线、行内代码（含多反引号）、键帽（[[Ctrl+w]]）、剧透遮罩（`||…||`，点开显形）、内外链接（含站内 .md 链接改写）、图片（含图注）、引用、无序/有序列表（start / 嵌套 / 多行项 / loose / 项内表格）、GFM 表格（对齐与单元格嵌套）、围栏代码块（含转义与行高亮）、折叠块（含长围栏与锚点接续）、提示框（含便笺内代码块与他块同规矩）、脚注（`[^1]` 引用与文末定义汇总）、分隔线、嵌套组合、HTML 转义与未闭合容错。若所有渲染都正常，说明解析器工作良好。

[^auto]: 构建时收走定义行、按首次引用顺序编号，再在最末拼出「脚注」区——定义写在哪里都行，位置自动归位。
[^bold]: 粗体里的引用，号码跟着粗体一起加粗。
[^hide]: 遮罩里的引用：揭开遮罩才看得见号码。
[^folded]: 折叠块里的引用，展开后照常出号。
[^link]: 定义正文里的站内 [.md 链接](./hyprland-config-lua.md) 白捡改写——点它会走到那篇文章；这条定义顺带演示了行内语法与链接改写。
[^quoted]: 引用块里的引用，样式跟着引用块走。
