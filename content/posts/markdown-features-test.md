这是一篇功能测试文档，覆盖当前博客 Markdown 解析器支持的全部语法。页面顶部应出现目录（本文有 9 个小节）。文章首段的首字应显示"下沉 + 金色"效果（仅首段）。

## 标题与段落

`#` 到 `######` 都支持，其中 `##` 和 `###` 会生成锚点并计入目录，其余层级仅渲染。段落支持多行合并、两端对齐。

普通段落文字。段落内可以**混排**各种行内语法：**粗体**、*斜体*、`代码`、[链接](https://example.com)、~~删除线~~。

## 粗体与斜体

- **粗体** `**粗体**`
- *斜体* `*斜体*`
- ***粗斜体*** `***粗斜体***`
- 嵌套：**粗体 *斜体* 互相嵌套**、*斜体**粗体**斜体*
- 粗体内容含星号：**a*b**（字面星号保留）
- 粗体套代码：**看 `code` 加粗**；粗体套链接：**看[链接](https://example.com)**
- 英文单词中间的单星号不误渲染：a*b*、foo*bar*baz

- 行内代码：`` `code` ``，代码内星号不误渲染：`a*b`
- 多反引号包裹含反引号内容：`` `` `code` `` ``（2 反引号包 1 反引号）
- 代码内特殊字符转义：`<b>&</b>` 显示为字面文本

## 代码块

围栏代码块（` ``` ` 三个反引号，可带语言标注）：

```js
function greet(name) {
  // 注释里的 <b>不会被解析</b>
  return `hello, ${name}!`;
}
```

无语言标注的代码块，内容中的 `<script>`、`&` 等应被转义显示：

```
<b>&</b>  <script>alert(1)</script>
```

## 分隔线与嵌套组合

分隔线 `---` 或 `***`：

---

各种行内语法互相嵌套：

- **粗体套斜体**：`**粗*斜*粗**` 渲染为 **粗*斜*粗**
- **斜体套粗体**：`*斜**粗**斜*` 渲染为 *斜**粗**斜*
- **粗体套代码**：```**a `b` c**``` 渲染为 **a `b` c**
- **删除线互套**：~~**粗体删除线**~~ 与 **~~删除线粗体~~**
