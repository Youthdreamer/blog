## Neovim 简单介绍

简单地说，Neovim 是 Vim 原版的一个**分支**，保留了 Vim 的经典全键盘操作。它并非要取代 Vim，但与 Vim 相比更容易维护与扩展，同时也带来更好的性能。配置方面，Neovim 可采用传统的 `init.vim` 配置，不过现在主流推荐使用 `init.lua`。

## Neovim 基本操作

接下来简单了解基本操作。

> **注意字母的大小写，大小写对应的操作会有所不同**

首先要了解的是，Neovim 的不同操作要在对应的模式下才能生效。

1. Neovim 模式

   | **模式** | **进入方式** | **可进行的操作** |
   | :--- | :--- | :--- |
   | **普通模式**（Normal） | 进入后默认在普通模式，可使用 `Esc` 切换到普通模式 | 光标移动，删除，复制，粘贴等 |
   | **插入模式**（Insert） | 在普通模式下按下 `i`、`a`、`o` 等 | 输入文本 |
   | **命令模式**（Command） | 在普通模式下按下 `:` | 输入命令，搜索，保存，退出等 |
   | **可视模式**（Visual） | 在普通模式下按下 `v`、`V`、`Ctrl-v` | 选中文本 |

2. 移动

   | **按键** | **使用效果** |
   | :--- | :--- |
   | `h`/`j`/`k`/`l` | 左/下/上/右移动 |
   | `w`/`b` | 下一个/上一个单词开头 |
   | `e` | 单词结尾 |
   | `gg`/`G` | 文件开头/文件结尾 |
   | `Ctrl+f`/`Ctrl+b` | 向下/向上翻页 |

3. 命令

   | **按键** | **使用效果** |
   | :--- | :--- |
   | `:w` | 保存文件 |
   | `:q` | 退出编辑器 |
   | `:q!` | 不保存退出 |
   | `:wq` | 保存并退出 |

## Neovim 配置介绍

Neovim 遵循 `XDG` 规范。

它是一套用于 Linux 等类 Unix 系统上管理用户配置、数据、缓存等文件存放位置的标准，目的是避免用户主目录被各种点文件（dotfiles）弄得混乱不堪。

### 核心目录

| 环境变量 | 默认路径 | 用途 |
|----------|----------|------|
| `XDG_CONFIG_HOME` | `~/.config` | 存放应用程序的配置文件 |
| `XDG_DATA_HOME` | `~/.local/share` | 存放应用程序的数据文件 |
| `XDG_CACHE_HOME` | `~/.cache` | 存放缓存文件 |
| `XDG_STATE_HOME` | `~/.local/state` | 存放应用程序状态（较新） |
| `XDG_RUNTIME_DIR` | 通常是 `/run/user/<uid>` | 存放运行时文件，如 socket、pid 等 |

所以 Neovim 遵循 XDG 规范的话：

- 配置放在 `~/.config/nvim/`
- 数据放在 `~/.local/share/nvim/`
- 缓存放在 `~/.cache/nvim/`

Neovim 是遵循这个规范的代表之一，因此它的配置文件位于 `~/.config/nvim/`，而不是传统的 `~/.vimrc`。

## Neovim 插件介绍

### 原生插件管理

[vim.pack](https://neovim.io/doc/user/pack/#_plugin-manager) 开箱即用，基本功能齐全，虽仍处在实验阶段，但满足日常使用完全足够。不过目前教程较少，从 `lazy.nvim` 配置迁移稍有成本；配置上需要考虑文件结构，不然后期维护较为困难。

### 社区主流插件管理器

[lazy.nvim](https://lazy.folke.io/) 提供极致的启动速度和便捷的懒加载能力。它基于 Lua 编写，充分利用 Neovim 的异步特性，是目前最受欢迎的插件管理器之一。其提供的 `VeryLazy` 触发事件，可让用户以非常简单的方式就达到很快的启动速度，不过该事件不是万能的，使用时请谨慎。

## Neovim 发行版（预配置版本）

> 成品方案，快速使用

Neovim 发行版是指**预先配置好的一套 Neovim 环境**，通常包含了精心挑选的插件、快捷键映射、主题、LSP 配置等，让用户开箱即用，无需从零搭建。

这些发行版本质上就是一套完整的 Neovim 配置（通常基于 Lua），可能还包含安装脚本、自定义命令和文档。它们的目标是降低上手门槛，同时提供现代化的编辑体验。

### 常见的 Neovim 发行版

| 发行版 | 特点 |
|--------|------|
| **LazyVim** | 基于 lazy.nvim，模块化设计，默认集成 LSP、Treesitter、Telescope 等，配置灵活，文档丰富 |
| **NvChad** | 界面美观，启动快，提供丰富的 UI 组件和主题，配置简单，适合喜欢炫酷界面的用户 |
| **AstroNvim** | 功能全面，默认配置强大，强调易用性和社区支持，文档完善 |
| **LunarVim** | 定位为 IDE 层，提供完整的开发环境，包含调试、测试、项目管理等，配置集中 |
| **Kickstart.nvim** | 不是完整发行版，而是一个极简的起始配置模板，适合学习和自行扩展 |

- **需要调整**：发行版可能不符合个人习惯，需要花时间调整
- **学习成本**：虽然开箱即用，但深入定制可能需要理解发行版的结构，学习曲线并不低
- **依赖较多**：预装了大量插件，下载会需要时间
